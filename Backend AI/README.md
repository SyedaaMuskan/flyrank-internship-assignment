## ▶️ Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
cd FlyRank-Backend-AI-Engineering
```

### 2. Create and activate a virtual environment

**Windows (PowerShell)**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**Windows (Command Prompt)**

```cmd
python -m venv .venv
.venv\Scripts\activate
```

### 3. Install dependencies

Navigate to the assignment you want to run and install its dependencies.

```bash
pip install -r BE-01-First-API/requirements.txt
```

### 4. Run the application

Each assignment contains its own instructions in its folder.

For example:

```bash
cd BE-01-First-API
uvicorn app.main:app --reload
```
