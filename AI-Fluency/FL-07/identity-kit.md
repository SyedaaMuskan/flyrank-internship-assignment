# AI Fluency — Week 03: Identity Kit

## Visual Direction

**Mood:** Minimal, modern, premium, calm, thoughtful, and editorial.

The visual identity is intentionally restrained. It should frame the work rather than compete with it, keeping the projects and case studies as the main focus.

## Typography

- **Heading Font:** DM Sans
- **Body Font:** Inter

DM Sans gives headings a clean and modern presence, while Inter keeps longer case-study content readable and simple.

## Color Palette

| Purpose | Color | Hex |
|---|---|---|
| Background | Warm White | `#F7F6F2` |
| Primary Text | Near Black | `#171717` |
| Secondary Text / UI | Charcoal | `#2D2D2D` |
| Accent | Muted Blue | `#6B7C93` |

The palette is intentionally limited to four colors. The muted blue accent should be used sparingly so the actual work remains the loudest visual element.

## Logo / Favicon

### Logo

A simple name wordmark set in **DM Sans**.

The wordmark is intentionally minimal and avoids unnecessary visual elements.

### Favicon

A clean monogram using my initials, following the same minimal visual language as the wordmark.

The favicon should remain simple and recognizable at a small size.

## Style Note

> **Fonts:** DM Sans for headings and Inter for body; palette: `#F7F6F2`, `#171717`, `#2D2D2D`, `#6B7C93`.
>
> **Mood:** Minimal, calm, thoughtful, and premium — use generous whitespace and restrained visual elements so the work remains the focus.

## Design Principles

### 1. Work First

The portfolio exists to present the work. The visual design should support the projects rather than become the main attraction.

### 2. Consistency

The same typography, colors, spacing, and visual treatment should be used throughout the portfolio.

### 3. Restraint

Avoid unnecessary gradients, decorative elements, excessive animations, and visual clutter.

### 4. Clarity

Typography, spacing, and layout should make the portfolio easy to scan and understand.

### 5. Intentionality

Every visual choice should have a clear purpose.

## What I Learned

This exercise taught me that a consistent visual identity does not require advanced design skills or a complicated design system.

A small number of deliberate decisions — one or two fonts, a tight color palette, a simple logo, and a clear mood — can make a portfolio feel intentional and coherent.

The most important judgment principle I learned is:

> **The design should frame the work, not compete with it.**

AI can generate many different visual directions, but the important skill is deciding which choices actually serve the work and rejecting the ones that create unnecessary noise.
