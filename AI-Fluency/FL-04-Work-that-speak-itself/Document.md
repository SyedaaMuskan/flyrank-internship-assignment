# Case Study 1 — TalentOS AI
## AI-Powered Hiring Intelligence Platform

### The Problem

Recruiters spend hours reading resumes, comparing candidates, and deciding who should move to the next hiring stage.

Traditional keyword matching often misses qualified candidates because it cannot understand the meaning behind resumes.

I wanted to build an AI-powered hiring assistant that understands resumes semantically and helps recruiters make faster and better hiring decisions.

---

### What I Built

I designed and developed TalentOS, an AI hiring platform that allows recruiters to:

- Upload resumes
- Extract structured candidate information using AI
- Store semantic embeddings
- Search candidates using natural language
- Compare applicants intelligently
- Generate interview questions automatically

The backend was built using FastAPI and Python.

During development I made an important architectural decision.

Originally the project used Azure AI Search and Azure services. After my Azure student credits expired, I redesigned the architecture instead of abandoning the project.

I migrated the system to:

- Supabase PostgreSQL for structured candidate data
- Supabase Storage for resume files
- Qdrant Vector Database for semantic search

This reduced costs while keeping the core AI functionality intact.

This experience taught me that engineering is often about adapting systems to real-world constraints rather than simply following tutorials.

---

### Outcome

TalentOS evolved into a production-style AI hiring platform capable of:

- AI resume parsing
- Semantic candidate search
- Intelligent candidate comparison
- AI-generated interview questions
- Scalable backend architecture

More importantly, I learned how to redesign an architecture when technical and financial constraints changed.

# Case Study 2 — CyberShield AI

## AI Cybersecurity Assistant

### The Problem

Cybersecurity concepts can be difficult for beginners to understand.

Many resources are scattered across documentation and require technical knowledge.

I wanted to create an assistant that could explain security concepts naturally while providing useful guidance.

---

### What I Built

I developed CyberShield AI using Python, FastAPI and Large Language Models.

The assistant accepts security-related questions and generates contextual responses that explain threats, best practices and defensive techniques.

Instead of returning static information, it provides conversational explanations tailored to the user's question.

---

### Outcome

The project demonstrated how LLMs can improve accessibility in cybersecurity education while helping me gain experience designing AI-powered backend APIs.

It also strengthened my understanding of prompt engineering and integrating LLMs into real applications.
